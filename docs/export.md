# Blueskyのリンクへの書き出し

編集者は、ボードのカードを選んで、本人のPDSの`app.bsky.actor.link`とプロフィールの`links`に書き出せる。用語は`docs/spec.md`に従う。

- 書き出すのは本人のPDSだけで、写しには書き込まない
- ボードを変えても自動では書き出さない。編集者が書き出したときだけ反映する

## 権限

ログインでは書き出しの権限を求めない。書き出すときに次の権限が無ければ、再ログインで追加の許可を求める。

| 対象                     | 操作         |
| ------------------------ | ------------ |
| `app.bsky.actor.link`    | 作成・削除   |
| `app.bsky.actor.profile` | 作成・更新   |
| PNGのblob                | アップロード |

## 書き出すカード

- 編集者がボードのカードから選ぶ。選ばなければ書き出せない
- `app.bsky.actor.link`のlexiconに合うカードだけを書き出せる。URLの無いカードは書き出せない
- lexiconに書かれていない制約は確認せず、Bluesky側に任せる
- 最大10枚まで
- カードのURLとテキストを、リンクの`url`と`title`にする。テキストが空なら`title`を付けない
- URLのドメインのファビコンをPNGにして、リンクの`icon`にする。取得できなければ`icon`なしで書き出す

## 置き換え

- プロフィールの`links`は、選んだカードで置き換える。プロフィールの他の値は変えない
- 置き換える前の`links`が指していた本人のリンクレコードは削除する。他人のレコードは削除しない
- 置き換えると元のリンクは戻せないので、書き出す前に編集者に確認する

## 失敗したとき

| 失敗                                 | プロフィールの`links` |
| ------------------------------------ | --------------------- |
| 選んだカードが書き出せない           | 変わらない            |
| PDSへの書き込みに失敗した            | 変わらない            |
| 書き出し中にプロフィールが変更された | 変わらない            |
| 古いリンクレコードの削除に失敗した   | 置き換わる            |

- 古いリンクレコードの削除の失敗は、書き出しの成功として扱い、警告だけ出す
- `links`が変わらなかった失敗でも、作りかけのリンクレコードは削除しない
