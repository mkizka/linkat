# Blueskyのリンクへの書き出し

編集者は、ボードのカードを選んで、本人のPDSの`app.bsky.actor.link`とプロフィール(`app.bsky.actor.profile/self`)の`links`に書き出せる。書き出すのはPDSだけで、写しには書き込まない。用語は`docs/spec.md`に従う。

## 入口

- `/export`で行う。ログインが必要で、ボードの写しが無ければトップにリダイレクトする
- 今は実験的な機能として扱う。`/experimental`で切り替えるCookieが無ければ、`/export`はトップにリダイレクトし、トップの「Blueskyに書き出す」は押せない「準備中」の表示にする
- ボードを変えても自動では書き出さない。変えたときは編集者がもう一度書き出す

## 権限

ログインでは`blue.linkat.permissionSet`だけを求め、書き出しに必要な権限は書き出すときに追加で求める。

| 権限   | 対象                     | 操作            |
| ------ | ------------------------ | --------------- |
| `repo` | `app.bsky.actor.link`    | create / delete |
| `repo` | `app.bsky.actor.profile` | create / update |
| `blob` | `image/png`              | アップロード    |

- `/export`を開いたとき、OAuthセッションのscopeが上の権限をすべて含むかを確かめる。足りなければ再ログインの画面を出す
- 再ログインは、上の権限を加えたscopeでOAuthの許可ページに移動し、終わったら`/export`に戻る
- 許可ページで拒否したときは、ログインをキャンセルした旨を出して`/export`に戻る

## カードの選択

- ボードのカードを並び順のまま表示し、書き出すカードを選ぶ
- `app.bsky.actor.link`のlexiconに合うカードだけを選べる。合わないカードは選べない表示にし、URLが無ければ「URLなし」、それ以外は「書き出し不可」と出す
- lexiconに書かれていない制約は確認せず、Bluesky側に任せる
- 最大10枚まで選べる。10枚選んだら、残りのカードは選べない
- 開いたときは、選べるカードを先頭から10枚まで選んだ状態にする
- 1枚も選んでいなければ書き出せない

## 確認ダイアログ

書き出すボタンを押すと、確認ダイアログを出す。プロフィールにリンクがあればすべて削除され、選んだカードに置き換わることを伝える。「書き出す」を選んだときだけ書き出す。

## 書き出しの処理

サーバーはカードの位置(インデックス)を受け取り、ボードの写しから対象のカードを引く。

1. 選択を検証する。0枚、ボードに無い位置、URLの無いカードを含むときは失敗にする
2. カードのURLとテキストを、リンクの`url`と`title`にする。テキストが空なら`title`は付けない。lexiconに合わないか、11枚以上ならエラーにする
3. 各URLのホスト名のファビコンを、DuckDuckGoのアイコンサービス(`https://icons.duckduckgo.com/ip3/{hostname}.ico`)から取得する
   - ICOなら、100KB以下で最も大きい画像をPNGにする。PNGなら100KB以下のときだけそのまま使う
   - 5秒で打ち切る。取得・変換できなければ`icon`なしで書き出す
4. 今のプロフィールのレコードを取得する。無ければ空として扱う
5. 選んだ順にリンクレコードを作る。アイコンがあれば先にblobとしてアップロードし、`icon`にする
6. プロフィールの`links`を、作ったリンクレコードの参照で置き換える。他のフィールドは変えない。手順4で取得したCIDを`swapRecord`に指定し、その間にプロフィールが変わっていたら失敗にする
7. 置き換える前の`links`が指していたリンクレコードのうち、本人のもの(`at://{did}/app.bsky.actor.link/`で始まるもの)を削除する。他人のレコードは削除しない

## 結果

| 結果                      | 表示                                                              | プロフィールの`links` |
| ------------------------- | ----------------------------------------------------------------- | --------------------- |
| 成功                      | 完了画面。Blueskyのプロフィールへのリンクとトップへのリンクを出す | 置き換わる            |
| 選択が不正(手順1・2)      | 「選んだカードが無効です」のエラー                                | 変わらない            |
| PDSへの書き込みの失敗     | 書き出しに失敗し、プロフィールのリンクは変わっていない旨のエラー  | 変わらない            |
| プロフィールの競合(手順6) | 書き出し中にプロフィールが変更された旨のエラー。再試行を促す      | 変わらない            |
| 古いリンクの削除の失敗    | 完了画面に加え、古いリンクの一部を削除できなかった旨の警告        | 置き換わる            |

- 失敗したとき、手順5で作ったリンクレコードは削除しない。プロフィールから参照されないレコードとしてPDSに残る
